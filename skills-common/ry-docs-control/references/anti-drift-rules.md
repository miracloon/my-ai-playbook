# 信息优先级与防漂移规则

> 纯查询手册——在需要判断"这个信息能否写入正文"时查阅。

---

## 信息来源优先级（从高到低）

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 用户当前轮明确裁定 | 最高优先，可覆盖一切 |
| 2 | 已确认的项目级控制文档 | 已成文的稳定结论 |
| 3 | 用户级全局偏好（AI_GLOBAL_PREFS） | 跨项目默认值 |
| 4 | 本 skill 中的规则 | 方法论层面的约束 |
| 5 | 仓库现状、已有代码 | 事实线索，非规范结论 |
| 6 | AI 的推断、常识补全、模板惯性 | 最低优先，需明确标注为候选 |

**冲突时以上层为准，并同步修订受影响文档。**

---

## 禁止行为清单

| # | 禁止行为 |
|---|---------|
| 1 | 补写用户未表达的目标、边界、长期方向 |
| 2 | 把当前代码结构直接写成 SPEC/WORKFLOW/INTENT 的规范正文 |
| 3 | 把探索性讨论写成确定性结论 |
| 4 | 让入口文档（AGENTS）替代核心文档承担正文职责 |
| 5 | 把"模板有栏目"误当成"栏目现在就应该写满" |
| 6 | 把提问退化成流水账式信息收集 |
| 7 | AI 主动宣告"已完成"或"足够开始生成" |
| 8 | 为了快速完成而跳过关键对齐 |
| 9 | 一次性抛出大量无层次的问题 |
