# 反代提醒事项

部署完成后，如果项目对反代有特殊要求，简要提醒用户在 1panel OpenResty 中注意。

## 用户的 OpenResty 默认配置

- `^~ /` 路径代理
- 常规超时
- 无 WebSocket 支持
- 无大文件上传支持（默认 `client_max_body_size`）
- CDN 开启

如果项目按此默认配置即可正常运行，不提醒。

## 需要提醒的场景

| 场景 | 提醒内容 |
|------|----------|
| WebSocket | 需要在反代中开启 WebSocket 支持（实时通信、在线编辑、协作等） |
| 大文件上传 | 需要调大 `client_max_body_size`（文件管理、图片/视频上传等） |
| 长超时 | 需要延长超时时间（长任务、流式响应、AI 推理等） |
| 非根路径 | 需要配置特殊路径规则 |
| CORS | 需要在 nginx 层处理跨域 |
| CDN 不兼容 | 建议关闭 CDN（WebSocket、大文件、实时流等场景） |

## 边界

提醒点到为止，不给出 nginx 配置详情。用户在 1panel 中自行完成反代配置。

## Compose 侧的反代准备

虽然反代本身由用户手动配置，但 compose 中涉及反代的配置项需要主动处理：

- **URL / 域名变量**（如 `APP_URL`、`BASE_URL`、`NEXTAUTH_URL`）——填入基于目标设备域名模板的实际域名
- **TLS / HTTPS**——反代层已终结 TLS，compose 内默认关闭应用层 TLS。主动定位项目中的 TLS 相关配置并关闭，确认不存在必须在应用层启用 TLS 的特例（如服务间 mTLS）
- **跨域 / CORS**——如果项目有跨域配置项，注意反代架构对跨域的影响，必要时在决策辅助阶段询问
