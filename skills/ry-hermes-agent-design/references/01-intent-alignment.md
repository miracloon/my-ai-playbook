# Stage 1: Intent Alignment

阶段1确认用户为什么需要这个 agent，以及最终想获得什么，避免带着方向性误读进入设计。

## 对齐内容

- 用户希望改善什么使用场景
- 核心目标、动机和成功图景
- 用户已经声明的前提或排除项
- 哪些内容是确定期待，哪些仍是模糊直觉
- 是否存在会改变整体方向的歧义或隐含期待

用户已声明的边界作为后续设计约束；agent 自身的功能边界在阶段2形成。

## 交互方式

- 用用户的场景语言对齐，不要求用户回答设计术语
- 信息充分时直接归纳；信息稀疏时只追问真正影响方向的分歧
- 不使用一次性问题清单，不为了完整补齐低价值信息
- 已提到不等于已对齐；关键意图需要形成共同理解
- 对齐内容随用户输入自然合并，不机械逐项询问

## 阶段边界

本阶段只处理会改变设计方向的信息，不定义 agent 的定位、功能、能力或工作路径。

## 完成标准

目标、动机、已声明边界和成功图景不存在已知的关键理解分歧，并获得用户确认。
