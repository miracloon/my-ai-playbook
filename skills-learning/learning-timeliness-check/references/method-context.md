# 单一方法的外部定位

适用于用户指向一个技术、方法或概念，希望跳出当前材料理解它的来历、变化和当下位置。

先识别真正被讨论的对象及其粒度。相邻层级可能需要不同判断，例如一种具体算法、它采用的设计机制和它所属的技术范式不能自动视为同一个对象。

围绕最能解释该方法的位置组织内容：

- 它回应了怎样的问题与既有限制，核心贡献是什么；
- 后续方法如何修正、替代、吸收或重新解释了它；
- 它今天是独立使用、作为组件存续、只保留思想，还是主要具有历史价值；
- 现在理解它时，真正值得保留的是问题意识、设计原则、具体方法、实现能力还是历史坐标。

这些是判断维度，不是固定章节。沿最有解释力的因果线展开，必要时比较直接相关的替代方案，不为补齐时间线罗列无关事件。

区分方法本身的现状与其思想的生命力。一个实现不再主流，不代表它解决的问题、形成的抽象或影响后续方案的设计判断已经失效。
