# 整份材料的外部定位

适用于用户指向一章、一组文档、一个项目或其他包含多种方法的材料，希望了解它在更大知识脉络和当下实践中的位置。

先理解材料自己的问题范围和方法关系，再从外部视角重新定位。不要逐项检查所有名词；识别真正构成材料主线的技术、方法、范式与关键转折。

重点观察：

- 材料建立在怎样的时代背景、默认前提和问题意识上；
- 其中的方法是演进、竞争、组合还是分支关系，关键变化由什么限制推动；
- 哪些内容今天仍是主流实践，哪些已被吸收或替代，哪些主要保留思想价值；
- 材料之外有哪些发展会实质改变用户对其内容和学习价值的理解。

沿材料已有的概念线索克制延伸，不把任务扩张成领域综述。材料中的边缘内容可以简略处理，承重节点和发生范式变化的位置应获得更多解释。

用连贯的因果叙述呈现整体位置。只有关系分支较多、图形确实比文字更清楚时才使用演化图；状态与成熟度直接准确地说明即可，不套固定标签体系。
