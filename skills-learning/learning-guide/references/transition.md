# 相邻学习单元的逻辑承接

适用于刚完成一个学习单元、准备进入下一个单元，需要恢复二者之间的问题链和认知连接。

结合前一个单元、下一个单元以及刚才实际发生的讨论，说明：

- 前一个单元建立了什么认识、处理了什么问题或提供了什么能力；
- 哪个限制、未完成的问题、新要求或视角变化使下一个单元有了位置；
- 下一个单元将接住怎样的问题，但不提前讲完它的解决方案。

材料逻辑是主要依据，对话上下文用于识别刚才真正展开过的重点和阻碍。不要因为讨论过某个内容就声称用户已经掌握，也不要把没有讨论过的内容伪装成共同结论。

相邻不代表因果。二者可能是问题驱动的延续、自然扩展、应用落地、替代方案、视角切换，也可能只是编排上相邻。准确说明实际关系；逻辑较弱时直接说，不制造“旧方法必然失败，所以新方法诞生”的伪必然性或伪历史。

承接的重点是让下一步提出的问题自然成立。保持凝练，不重复总结整篇，也不转入下一单元的正式讲解。下一个对象无法从当前上下文可靠确定时，再请用户指出目标。
