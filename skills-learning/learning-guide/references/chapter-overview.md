# 章节或阶段导读

适用于被组织为一个章节、阶段或主题区块，并由多个小节、文档或学习单元共同推进的材料。

从整章的高度显化：

- 这一章为什么在整体中出现，它接住了什么背景或问题；
- 全章真正围绕的核心问题、矛盾或认知变化是什么；
- 各单元怎样推动这条主线，顺序背后有哪些依赖、转折或逐步增加的要求；
- 哪些部分承担核心认识，哪些用于例证、实现、比较或补充边界；
- 从章首到章末，理解对象的方式发生了什么变化。

不要把章节导读写成每篇材料等量展开的摘要合集。单元只作为整体推进中的节点出现，篇幅由它在问题链中的作用决定。

补出作者默认读者能够自行连接的前提与过渡，但不要提前讲完各单元的具体机制。材料内部关系薄弱、只是并列介绍或编排相邻时，如实呈现，不强行构造统一主线和必然因果。

章节导读应提供高于局部内容的认知位置，而不是增加一层更抽象但同样沉重的术语。
